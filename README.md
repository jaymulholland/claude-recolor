# claude-recolor

Make Claude Code's orange any colour you want.

The Claude Code VS Code extension has no accent-colour setting. This is a recipe your Claude agent follows: it helps you pick a colour, patches the extension, and re-applies it after every update.

## Use it

1. Save [`CLAUDE-CODE-RECOLOR.md`](CLAUDE-CODE-RECOLOR.md) somewhere and open Claude Code in that folder.
2. Say `follow CLAUDE-CODE-RECOLOR.md`.
3. Pick a colour: from VS Code's colour picker, a preset palette, a description ("dusty teal") or a hex.
4. Run **Developer: Reload Window** (Ctrl/Cmd+Shift+P).

Works with VS Code, Insiders, Cursor and Windsurf on Linux and macOS (Windows via Git Bash or WSL). Originals are backed up, and the recipe explains how to restore them.

Unofficial, not affiliated with Anthropic. It edits installed extension files; use at your own risk.
